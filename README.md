### 📉 Customer Churn Prediction — Live Deployed ML Web App

**`Python` · `Pandas` · `Scikit-learn` · `SMOTE` · `Decision Tree` · `Random Forest` · `Streamlit`**

Full ML pipeline on 7,043 telecom customer records. EDA → feature engineering → SMOTE class balancing → model training → deployed as a live Streamlit web app with real-time churn probability output.

| Metric | Result |
|---|---|
| 🎯 Model Accuracy | **82%** (vs 73% naive baseline) |
| ⚖️ Class Imbalance Fix | SMOTE — 73% No Churn / 27% Churn → balanced |
| 🧠 Models Trained | Decision Tree · Decision Tree + SMOTE · Random Forest |
| 🌐 Deployment | Live Streamlit Cloud app |
| 📦 Dataset | 7,043 customers · 21 features · IBM Telco Churn |

A model that always predicts "No Churn" scores 73% by default — it's useless. At 82% with SMOTE, this model learns actual churn patterns. Out of 100 at-risk customers, it correctly flags ~82 — giving retention teams a real signal to act on.

🌐 **[Live App →](https://raghav010-churn-prediction.streamlit.app)** &nbsp;|&nbsp; 📁 **[GitHub →](https://github.com/raghav-010/customer-churn-prediction)**

### 🔵 Unsupervised Learning — K-Means Clustering & PCA

**`Python` · `Scikit-learn` · `NumPy` · `Pandas` · `Matplotlib`**

Clustering and dimensionality reduction on the Iris dataset — built to understand what evaluation metrics alone can't tell you.

- K-Means across 6 experiments (K=2 to K=7) — evaluated with Inertia and Silhouette Score
- Best Silhouette Score: **0.68 at K=2** · K=3 Inertia ~78.85 matching real-world class structure
- PCA applied to compress 4D feature space into 2D for visual interpretation
- Key finding: mathematically optimal K differed from domain knowledge ground truth — metrics and business context must be combined

📁 **[GitHub →](https://github.com/raghav-010/unsupervised-learning-kmeans-pca)**
